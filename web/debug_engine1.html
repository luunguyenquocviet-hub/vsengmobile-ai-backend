📋 Kịch bản tự kiểm chứng Engine ①
1. Trong app, dùng 2–3 user khác nhau cùng xem/click 2 sản phẩm A và B bất kỳ.
2. Chạy python scripts/retrain_model.py rồi restart uvicorn (ma trận chỉ đổi khi train lại — khác Engine ② real-time).
3. Quay lại đây soi A: B phải xuất hiện trong top tương tự, và phần "user chung" liệt kê đúng các user bạn vừa dùng.
4. Trọng số hành vi khi train: view=1, click=2, wishlist=3, cart=4, buy=5 — user nào mua cả 2 máy sẽ kéo cosine mạnh hơn user chỉ xem.
